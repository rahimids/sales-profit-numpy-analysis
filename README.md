# Sales-profit-numpy-analysis
# Sales and Profit Analysis with NumPy

## Project Overview

This project analyzes the relationship between Sales and Profit using NumPy and Matplotlib.

## Dataset

The dataset contains sales and profit information for customer orders.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Mean calculation
- Median calculation
- Standard deviation
- Percentile analysis
- Correlation analysis
- Data visualization

## Key Findings

- Most orders have sales below 5,000.
- There is a moderate positive relationship between Sales and Profit.
- The correlation coefficient between Sales and Profit is 0.47.
- Some high-sales orders generate losses.
- Sales alone cannot fully explain profit variations.

## Visualizations

- Sales Distribution Histogram
- Sales vs Profit Scatter Plot

## Conclusion

Sales and Profit show a moderate positive relationship. However, orders with similar sales values can have very different profit values, suggesting that additional factors affect profitability.
